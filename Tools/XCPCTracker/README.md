# XCPC 赛站题评

一个通过结构化数据自动生成赛站大表与知识点逆向索引的工具。

（目前知识点反查较为粗糙，暂无层级分类）

## 文件说明

* data.yaml: 数据源，赛站、出题组以及各难度知识点。
* generate.py: 生成脚本。
* INDEX.md: 自动生成的文件，展示赛站表。
* TAGS.md: 自动生成的文件，展示知识点逆向索引。

## 使用方法

### 1. 录入数据

打开 data.yaml，按照现有格式追加数据。

### 2. 本地生成表格

在当前目录下运行以下命令：
python generate.py

运行后会自动更新 INDEX.md 和 TAGS.md。
